## What to build

### 1. Entry points

- `src/simulate_chunk.cpp` with `// [[Rcpp::export(name = ".simulate_chunk_cpp")]]` (default `rng = true`)
  taking `(IntegerVector sim_indices, List cfg)`. One chunk, single-threaded, R's own stream through `R::`
  samplers and `unif_rand`, no callback into R that draws. Use `evt_rsem::` helpers from `src/r_semantics.h`
  for every `sum`, `mean`, `median`, quantile, `findInterval`, logical `mean`, `seq(0, 1, length.out = )` and
  cutpoint rebalancing. No reduction in plain double where R reduces in long double.
- Call the existing gamma sampler's C++ body directly from C++ (refactor it into a shared internal function
  if needed, leaving its exported signature and its draws unchanged). Do not reimplement it.
- In `run_simulation_pure`, after the definition of `simulate_chunk_r` and before the seam's
  `chunk_probe` return, add:
  - `cfg <- .pack_chunk_cfg(environment())` (or an equivalent name), built once per frame from the free
    variables in inventory Section 1. It must not draw from the stream. It must force `looks_stop_at_final`.
  - `simulate_chunk_cpp <- function(sim_indices, seed = NULL, tick = function() {}) { if (!is.null(seed)) set.seed(seed); .simulate_chunk_cpp(sim_indices, cfg) }`.
    It must `stop()` with a clear message when the configuration is outside the supported set. It never
    falls back. (A candidate that falls back would let layer 1 compare the R body with itself and pass.)
  - `simulate_chunk` becomes the dispatcher: `simulate_chunk_cpp` when
    `isTRUE(getOption("evolveTrial.use_cpp_engine", TRUE))` and the supported-set predicate holds, otherwise
    `simulate_chunk_r`. Replace the seam's `simulate_chunk <- simulate_chunk_r` line with this. The rest of
    the driver keeps calling `simulate_chunk` as now.
- Run `Rcpp::compileAttributes()` and check that the diff of `R/RcppExports.R` and `src/RcppExports.cpp` is
  additions only (B3). Quote that diff summary in the report.
