Date 2026-11-04. Parent plan `2026-11-04-phase3-plan.md` (Section 1 rules hold here). Item numbers are those of
`2026-11-04-phase3-coverage-inventory.md`. Branch `perf/merge-main`, worktree `~/research/evolveTrial-merge`, base

## 1. Goal

After P3-2 the paper's bidirectional rows (interim efficacy stopping on, 25 of 39 single-arm and 28 of 35 multi-arm
production rows) and the symmetric rule variant (an HR efficacy margin on the between-arm path) run on the exact
engine. Every frame the predicate admits gives the R body's result in the phase 1 engine bit for bit. The R body is
the reference and is not edited.

## 2. What the R body does (read before porting)

- HC interim (`R/interim_logic.R` 43-66, 238-260). `calculate_current_probs_hc` always computes both
  `pr_eff = mean(med_draws > success_thr)` and `pr_fut = mean(med_draws < futility_thr)` from one set of draws. The
  draws do not depend on the rule, so turning the rule on does not change the RNG stream. The efficacy check comes
  first: `isTRUE(efficacy_stopping_rule_hc) && !is.null(efficacy_threshold_hc_prob) && is.finite(...) && pr_eff >= thr`
  sets `stopped_efficacy`, `stop_efficacy_per_sim_row = 1`, `sim_final_n_current_run = enrolled`, `stop_time`, then
  `next` (futility not evaluated). Interim `success_thr` resolves as `(median_pfs_success_threshold_arms %||%
  null_median_arms)[[arm]] %||% vec[1]` (IL:57-61), which P3-1 left unread (predicate item 10 comment).
- Vs-ref interim (`IL:1-41`, `IL:146-166`). `pr_eff = mean(logHR < log_eff)`, `pr_fut = mean(logHR >= log_margin)`
  from the same PH draws. `log_margin = 0` when `compare_arms_hr_margin` is NULL, `log_eff = 0` when
  `compare_arms_hr_eff_margin` is NULL, otherwise `log1p(-min(max(0, m), 0.95))`. Efficacy is checked first under the
  same guard shape as HC with `efficacy_stopping_rule_vs_ref` and `efficacy_threshold_vs_ref_prob`.
- Final (`R/simulation_driver.R` 851-937). Arms not recruiting are skipped, so an arm stopped for efficacy at an
  interim makes no final draws, exactly as an arm stopped for futility. The final already reads both HR margins
  (`SD:906-918`).
- Summary (`SD:1211-1225`, `SD:1249-1254`). Power is `early_eff + final_eff`, `PET_Efficacy = early_eff`,
  `Pr_Reach_Max_N = 1 - early_eff - early_fut`. Variances are `prop_var` of these aggregates, so the engines need
  only the `stop_eff` counts they already return.

The packer gains `eff_interim` (logical: rule TRUE and probability threshold one finite number), `eff_prob_interim`
(HC), `vr_eff_prob_interim` (vs-ref) and `success_thr_interim` per arm (HC). The rule flags are read from `args`

admitted it is read whenever `eff_interim` is TRUE, so item 10's interim condition must require it to resolve to a
number, mirroring the existing futility condition under 13c.

## 4. Breakage inventory

| What can break | Where | Guard |
|---|---|---|
| Efficacy checked after futility, or futility evaluated after an efficacy stop | both interim functions, both engines | Gate B frames where both `pr_eff >= thr_E` and `pr_fut >= thr_F` can hold at one look (low thresholds), with a count of looks where both held |
| HC `pr_eff` uses `>=` instead of `>`, or the final success threshold instead of the interim one | tallies, packing | Frames where the interim and final success thresholds differ (`null_median_arms` fallback vs `median_pfs_success_threshold_arms`) |
| McPost draws twice for the two tails (RNG drift) or the exact engine calls a second posterior | policy class | Gate B `.Random.seed` comparison after every chunk |
| Rule TRUE with NULL or Inf probability threshold packed as a stop | packer | Frames with rule TRUE and threshold NULL, and with Inf; expected result equals rule FALSE bitwise |
| NA `pr_eff` (unresolvable interim success threshold) silently treated as no stop where the R body errors | packer, predicate | Exclude such frames in the predicate, plus a fallback test |
| An efficacy-stopped arm treated differently from a futility-stopped arm downstream (final skip, `final_n`, trial end, Exp_Time, vs-ref phantom exit, amd8 all-stopped branch) | trial loop, final block | Frames where efficacy stops are frequent (alternative, low `thr_E`), under P6 on and P6 off, single-arm and vs-ref |
| HR margins: the efficacy margin with a NULL futility margin, a margin above 0.95 (capped), a negative margin (clamped to 0) | packing | Frames for `symmetric` (both margins set), `no_margin` (both NULL or 0), eff margin only, and 0.97 |
| A P6-on frame without efficacy changes | both engines | Goldens 6/6 bitwise identical, `p30_onpath_vs_37.R` 15/15 |
| Predicate admits more than items 9, V5, V6 | `R/simulate_chunk_cpp.R` | A test that one frame from each still-excluded item (2, 3, 5, 12, V2, V3, V4, V9, 13a) still falls back |
| hetGP variance not filled | `return_variance = TRUE` | Every gate B and S frame runs with it; `Var_PET_Efficacy` nonzero on efficacy frames |
| Worker-count dependence | per-trial streams | `p31_g3.R` pattern on two new frames |
| Paper wrapper rows change engine (R body to exact) | users | NEWS entry, `options(evolveTrial.engine = ...)` restores the R body |

## 5. Gates

- **B.** Phase 1 engine `identical()` to the R body, table and `.Random.seed`, on new frames from the R01, R03 and R23
  fixtures (`dev/perf/phase3/p31_frames.R` pattern): HC efficacy on under P6 on and off, null and alternative, both
  stop types competing at one look, rule TRUE with NULL and with Inf probability threshold, interim and final success
  thresholds differing, efficacy on with NULL interim futility; vs-ref efficacy on with margins `current`, `symmetric`,
  `no_margin`, eff-only and capped, P6 on and off. Branch-hit counts per frame (efficacy stops, both-held looks). Then
  layer 1 on the old designs plus the new frames, with chunk counts.
- **S.** Exact engine against fresh R-body runs at fresh seeds, phase 2 margins (power 0.01, type I error 0.005,
  expected sample size 1%). Frames at least: HC bidirectional P6 on, HC bidirectional P6 off, vs-ref bidirectional
  `current`, vs-ref bidirectional `symmetric`, each under null and alternative. Trial counts are fixed in advance from
  a pilot spread so every statistic has test power of at least 0.95 at a true difference of 0 (handoff lesson 6).
  The sizing calculation is written into the report before the runs start. No extension after a readout.
- **T.** Full suite 0 failures. New frames in `test-engine-equivalence.R` (routine and long tiers) and new golden
  entries. Existing golden entries unchanged.
- **R.** Codex review of the P3-2 commits by the coordinator.
