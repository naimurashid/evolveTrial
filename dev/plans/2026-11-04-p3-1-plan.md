## 1. Goal

After P3-1 a call with all options unset on the single-arm path (`run_simulation_pure()` with no
`looks_stop_at_final`, dropout on, `max_trial_time = Inf`, no rebalancing, NULL median thresholds, NULL interim
futility threshold) runs on the exact engine, and every frame the predicate admits gives the R body's result in the
phase 1 engine bit for bit. The R body is the reference and is not edited, except for comments that P3-0 left stale.

## 4. Gates

- **B.** Phase 1 engine `identical()` to the R body, table and `.Random.seed`, on new acceptance frames built from the
  R01, R03 and R23 fixtures. Frames cover: P6 off with a binding cutoff, F = 0, F > 0, F < 0 if the R body allows it,
  `max_trial_time = Inf` under P6 off and P6 on, dropout on under both chronologies, rebalancing NULL, each threshold
  fallback, NULL interim futility, vs-ref P6 off with phantom exits, and one frame with everything unset. Then the layer
  1 harness (`dev/perf/harness/run_layer1.R`) on the old designs plus the new frames, with chunk counts.
- **S.** Exact engine against fresh R-body runs at fresh seeds, two one-sided tests with the phase 2 margins (power
  0.01, type I error 0.005, expected sample size 1%), on at least the everything-unset frame, a binding-cutoff P6-off
  frame, a dropout frame and a vs-ref P6-off frame, each under the null and the alternative. Run locally as in phase 2.
- **T.** Full suite 0 failures. New frames in `test-engine-equivalence.R` (routine and long tiers) and new entries in
  the golden fixture. Existing golden entries unchanged.
- **R.** Codex review of the P3-1 commits by the coordinator.
